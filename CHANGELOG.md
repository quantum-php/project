# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog and this project adheres to Semantic Versioning.

## [3.1.2] - 2026-11-19

### Added
- The `comments.added` and `comments.deleted` texts, in English and Spanish, for the flash messages of the framework's `DemoWeb` comment controller. They were called but never defined, so the page showed the key names (#216).

### Changed
- The translations in `shared/resources/lang/{en,es}` are split by topic, as the `DemoWeb` and `DemoApi` module templates of quantum/framework 3.1.2 expect: `pages`, `auth`, `account`, `posts`, `comments`, `actions` and `lang`. The texts are unchanged. `common` keeps the keys the framework reads by name: `activate_account`, `reset_password`, `otp`, `pagination` and the field labels the validator reads as `common.<field>`. The email views in `shared/views/email` use the new keys, for example `auth.activate` instead of `common.activate`. A module generated by framework 3.1.2 or newer needs these files; modules generated earlier call the old `common` keys (#216).
- The starter config reads its boolean and integer settings with the framework's `env_bool()` and `env_int()` instead of `env()`, so they hold a real `bool` or `int` instead of the `.env` text: `debug` and `resource_cache` in `shared/config/app.php`, the SMTP `port` in `shared/config/mailer.php` (default `25`) and the Redis `port` in `shared/config/rate_limit.php` (default `6379`). `.env.example` sets `MAIL_PORT=25`, because `env_int()` rejects an empty value. Existing projects keep their config; a project that copies these lines and has an empty `MAIL_PORT` in its `.env` must set it to a number (#212).

## [3.1.1] - 2026-11-03

### Added
- A message at the end of `php qt install:demo` that invites you to star Quantum on GitHub, with the link `https://github.com/quantum-php/framework`. It is shown only when the demo was created successfully (#194).
- The `common.star.message`, `common.star.button` and `common.star.badge_alt` texts, in English and Spanish, for the star block that the framework's `DemoWeb` About page shows. Without them the page shows the key names (#194).

### Fixed
- `php qt install:demo` no longer stops with "unable to get local issuer certificate" on a PHP that has no CA bundle configured: `save_remote_image()` and `save_remote_images()` download the public demo images with `CURLOPT_SSL_VERIFYPEER` off. The certificate of those downloads is not verified (#194).

## [3.1.0] - 2026-10-24

### Added
- A `cache/` folder for runtime cache files such as the file rate limiter's data. Its contents are git-ignored, so a fresh install no longer fails the first rate-limited request.
- The `resend` mailer entry in `shared/config/mailer.php` and `RESEND_APIKEY` in `.env.example`.
- A `save_remote_images()` helper that downloads the demo images in parallel; `php qt demo` uses it.
- An API smoke test in CI.
- `logging.message.limit` and `mailer.transport_log_limit` in the config: the number of log messages and transport log lines kept in memory, both `1000` by default (framework #593).

### Changed
- `shared/config/lang.php` uses the 3.1 Lang format: `default` adapter (`file`, `deepl` or `google_translate`), `default_locale` and a section per remote adapter.
- `save_remote_image()` uses the fluent `httpRequest()` helper.
- CI runs `composer rector:check` after PHPStan.
- The DTOs and services use `readonly` properties, and null values are cast to strings where they reach string functions (`trim()`, `strtotime()`, `preg_replace()`), as the Rector PHP 8.1 level set proposes.
- **Breaking:** the minimum PHP version is 8.1 (`composer.json`, README, PHPStan `phpVersion` and the Rector level set), and CI runs on PHP 8.1, 8.2 and 8.3, following the framework (quantum-php/framework#595).

### Removed
- The `Hook`, `Loader` and `libraries/` leftovers: the `hooks/` and `libraries/` folders, `shared/config/hooks.php` and the hooks and loader entries in the dependencies config.
- The unused Travis CI configuration (`.travis.yml`).

## [3.0.3] - 2026-07-10

### Changed
- Raised the project runtime baseline to PHP 8.0 and updated CI to exercise PHP 8.0, 8.1, and 8.2.
- Bumped the PHPStan parser baseline to PHP 8.0.
- Aligned the downstream framework dependency to stable `quantum/framework` `3.0.3`.

## [3.0.0] - 2026-05-28

### Changed
- Upgraded downstream framework dependency from `quantum/framework` `dev-master` to stable `3.0.0`.
- Updated `.env.example` default `APP_VERSION` from `2.9.9` to `3.0.0`.

### Notes
- This release aligns the downstream project with upstream `quantum/framework` `3.0.0`.
