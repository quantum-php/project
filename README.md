<h2>Installation</h2>

<p><strong>Requirements:</strong> PHP 8.1 or newer.</p>

<h3> 1. Create new project </h3>

```bash
composer create-project quantum/project [your-project-name]
```

<h3>2. Run the server from your project directory</h3>

```bash
php qt serve
```
